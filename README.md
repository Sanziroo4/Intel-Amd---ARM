# CHIP ATLAS

Intel, AMD және Arm туралы қазақша статикалық оқу сайты. Автор: **Сейтқазы Санжар**.

Монохромды дизайн, авторлық SVG сызбалар, ашылатын оқу карточкалары, салыстыру кестесі, CPU нұсқау циклі, кэш/RAM интерактиві, бес өмірлік сценарий, мифтер, сегіз сұрақтық тест, ізделетін сөздік және ресми дереккөздер.

## Іске қосу

Node.js 22 немесе жаңасы жеткілікті. Қосымша backend, API кілті, сыртқы қаріп пен runtime кітапханасы қажет емес.

```sh
npm ci
npm run dev
```

Жергілікті сервердің порты — 4173. Өзге порт: `PORT=4180 npm run dev`.

## Production build және тексеру

```sh
npm run build
npm run preview
npm test
```

`dist/` — жарияланатын дайын сайт. Playwright тесттері жүйедегі `/usr/bin/chromium` браузерін пайдаланады. Басқа орынды `CHROMIUM_PATH` айнымалысымен беруге болады. Тексерулер мәзірді, барлық 21 ашылатын блокты, интерактивтерді, тестті, іздеуді, азайтылған қозғалысты, 320–1440 px орналасуды және жергілікті ресурстарды қамтиды. Видео берілсе, сол файлды ойнату мен уақыт бойынша жылжыту да тексеріледі; файл жоқ күйді тексеру ойнатудың дәлелі емес.

## Видео қосу немесе ауыстыру

Бастапқы `Intel and AMD.mp4` тіркемесі ортаның 32 МиБ тасымалдау шегінен үлкен болғандықтан, бастапқы іске асыру кезінде файлды ашу мүмкін болмады. Сондықтан сайтта нақты белгіленген күту күйі бар. Ойдан шығарылған ұзақтық, субтитр немесе тарау қосылмаған. Бұл бөлік файл берілгенше аяқталмаған.

1. Түпнұсқаны checkout сыртында сақтаңыз. Оны қайта жазбаңыз.
2. `ffmpeg` және `ffprobe` бар ортада веб көшірме жасаңыз:

```sh
npm run video:prepare -- '/absolute/path/Intel and AMD.mp4'
```

Бұл команда H.264/AAC, ені ең көбі 1280 px, `yuv420p`, `faststart` MP4 жасайды, нақты ұзақтығын өлшейді және `assets/media.json` манифесін жаңартады. Түпнұсқаны өзгертпейді. Нәтиже бар болса, оны автоматты қайта жазбайды. 90 МиБ — осы жобаның сақтық бюджеті; хостингтің ағымдағы ресми шектеуін жеке тексеріңіз. Ұзын видео үшін битрейтті азайту немесе қолжетімді сыртқы сақтау қажет болуы мүмкін.

3. `npm run build && npm test` орындаңыз. Видеоны шын ойнатып, дыбысын, уақыт жолағын және толық экранды браузерде тексеріңіз.
4. `assets/intel-and-amd.mp4` және жаңарған манифесті commit-ке қосыңыз. Git LFS pointer қолданбаңыз.

Тікелей сыртқы MP4 URL қолданылса, оны `assets/media.json` ішіндегі `src` өрісіне қойыңыз. HTTPS, қолжетімділік және range request қолдауын тексеріңіз. Видео `preload="metadata"` арқылы жүктеледі, дыбыспен автоматты басталмайды. Ұзақтығы браузердегі нақты metadata-дан көрсетіледі. Мұқаба — сайттың жеке SVG иллюстрациясы; видеодан алынған кадр емес.

## GitHub Pages

Нақты репозиторий: <https://github.com/Sanziroo4/Intel-Amd---ARM>.

1. Өзгерістерді `main` тармағына push етіңіз.
2. GitHub-та **Settings → Pages → Build and deployment → Source → GitHub Actions** таңдаңыз.
3. `.github/workflows/pages.yml` build және deploy жасайды.
4. Әрекеттің сәтті аяқталғанын және жарияланған URL-ді тексеріңіз.

Күтілетін Pages жолы: `https://sanziroo4.github.io/Intel-Amd---ARM/`. Бұл адрес тек deployment сәтті болып, жауап тексерілгеннен кейін жұмыс істейтін сілтеме деп есептеледі. Барлық актив жолдары салыстырмалы (`./assets/...`), сондықтан репозиторий префиксі сақталады. Қосымша SPA redirect қажет емес.

Git push құқығы GitHub API немесе Pages баптау құқығын білдірмейді. API не аккаунт рұқсаты болмаған жағдайда Pages-ты пайдаланушы баптауы керек. Бұл жоба ортаның өзін жарияламайды.

## Қолжетімділік және мазмұн

Семантикалық HTML, қазақ тілі, native `details` және video басқаруы, пернетақта focus-ы, tab пернелерімен жұмыс, skip-link, `aria-live`, `prefers-reduced-motion` және сақталатын анимация ауыстырғышы бар. Оқу CPU моделі нақты процессордың толық моделі емес. Симуляция уақыттары өнімділік өлшемі емес.

ISA, микроархитектура және компания рөлдері ажыратылған; ойдан шығарылған benchmark немесе бренд жеңімпазы жоқ. Дереккөздер сайтта берілген. Алғашқы ортада өндірушілердің домендеріне шығуды желі саясаты бұғаттады; сілтемелердің ағымдағы ашылуын және өнім мысалдарының ресми тексеруін аяқтау үшін сол домендерге қолжетімділік қажет.

## Файлдар

- `index.html` — қазақша материал және семантикалық құрылым.
- `styles.css` — бейімделетін монохромды дизайн.
- `app.js` — интерактивтер, тест, мәзір, видео манифесі.
- `assets/` — SVG графика, мұқаба, media манифесі және берілгеннен кейін видео.
- `scripts/` — build, range request қолдайтын жергілікті сервер, видео дайындау.
- `tests/` — браузерлік тексерулер.
